# Салон красоты «Африка» — сайт

Статичный одностраничный сайт салона красоты «Африка» (Пермь, 1-я Красноармейская ул., 41А, офис 5).

- `index.html` — разметка
- `styles.css` — стили и анимации
- `script.js` — интро, прайс, отзывы, анимации при скролле
- `assets/` — логотип и изображения

Информация об услугах, ценах, графике и отзывах взята с Яндекс Карт.
Сборка не нужна: Vercel раздаёт файлы как есть, каждый пуш в `main` деплоится автоматически.
